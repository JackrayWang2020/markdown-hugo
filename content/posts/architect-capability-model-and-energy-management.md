## 二、字节 3-2 / 架构师能力模型

### 2.1 能力全景图

| 能力维度 | 3-1（高级） | 3-2（架构师） |
|---------|-------------|---------------|
| **技术深度** | 精通 Flink | 精通 Flink + 数据湖 + 推荐系统 + 实时数仓 |
| **技术广度** | 大数据领域 | 大数据 + AI + 架构 + 云原生 |
| **架构能力** | 单系统设计 | 多系统协同、架构演进、技术选型 |
| **决策能力** | 技术决策 | 战略决策、成本决策、风险决策 |
| **影响力** | 团队内 | 开源贡献、技术分享、跨团队影响 |
| **管理能力** | 无 | 带团队、技术规划、项目管理 |
| **业务能力** | 理解业务 | 深入业务、技术赋能业务、主动发现需求 |
| **沟通能力** | 技术沟通 | 跨团队沟通、向上汇报、对外交流 |

### 2.2 核心能力详解

#### 技术决策能力

| 决策类型 | 具体要求 |
|---------|---------|
| **技术选型** | 评估多个方案（成本/性能/风险），给出决策依据 |
| **架构演进** | 识别技术债务，制定演进路线，渐进实施 |
| **成本决策** | 技术投入 vs 业务收益，ROI 分析 |
| **风险决策** | 技术风险评估、容灾方案、降级策略 |

**提升方法**：
- 每次技术选型写决策文档（对比分析）
- 复盘失败决策，总结教训
- 学习其他公司技术演进案例

#### 战略规划能力

| 规划类型 | 具体要求 |
|---------|---------|
| **技术路线** | 1-2年技术演进规划 |
| **团队规划** | 团队能力建设、人员培养路径 |
| **资源规划** | 人力、硬件、成本预算 |
| **风险规划** | 潜在风险识别、应对预案 |

#### 管理能力

| 管理类型 | 具体要求 |
|---------|---------|
| **团队管理** | 招聘、培养、绩效、激励 |
| **项目管理** | 项目规划、进度控制、风险应对 |
| **技术管理** | 技术规范、代码Review、技术分享 |
| **跨团队协作** | 协调资源、解决冲突、推动落地 |

#### 业务赋能能力

| 能力 | 具体要求 |
|------|---------|
| **业务理解** | 理解业务指标、用户需求、商业模式 |
| **主动发现** | 发现业务痛点，主动提出技术方案 |
| **价值量化** | 技术收益量化（延迟降低 → 转化率提升） |
| **业务创新** | 用技术创造新业务机会 |

#### 沟通影响力

| 沟通场景 | 具体要求 |
|---------|---------|
| **向上汇报** | 简洁清晰、数据驱动、结论先行 |
| **跨团队沟通** | 理解对方需求、找到共赢点、推动协作 |
| **技术分享** | 结构化表达、案例驱动、互动答疑 |
| **开源社区** | 英文沟通、Proposal撰写、PR讨论 |

## 三、AI时代核心竞争力

### 3.1 被替代 vs 新能力

| 被AI替代的风险 | 新核心竞争力 |
|---------------|-------------|
| 写代码 → AI写更快 | **系统设计、架构决策** |
| 查资料 → AI秒答 | **问题定义、需求洞察** |
| 调参数 → AI自动调 | **技术选型、成本决策** |
| 写文档 → AI生成 | **沟通协调、推动落地** |
| 算法实现 → AI更快 | **业务理解、价值创造** |

**结论：AI擅长执行，不擅长决策。提升决策能力。**

### 3.2 技能转型

| 旧技能（AI替代） | 新技能（AI增强） |
|-----------------|-----------------|
| 写代码 | **用AI写代码 + Review + 设计** |
| 调Bug | **用AI定位 + 决策方案** |
| 学新框架 | **用AI加速学习 + 深度理解** |
| 写文档 | **用AI生成 + 审校完善** |

**转变：从执行者变成指挥者。**

## 五、高能状态管理

### 5.1 能量公式

```
高能状态 = 身体能量 + 精神能量 + 工作能量 + 心理能量
```

### 5.2 身体层面

| 维度 | 方法 |
|------|------|
| **睡眠** | 7-8小时、固定作息、午休20分钟 |
| **运动** | 每天30分钟、周末户外 |
| **饮食** | 少糖少油、多蛋白、按时吃饭 |
| **休息** | 番茄钟（25分钟 + 5分钟） |

**关键：睡眠最重要。**

### 5.3 精神层面

| 维度 | 方法 |
|------|------|
| **目标感** | 清晰目标、分解里程碑、每日推进 |
| **成就感** | 完成记录、贡献可视化、进步清单 |
| **意义感** | 理解工作价值、赋能业务 |
| **好奇心** | 保持学习、探索前沿 |

**关键：目标清晰 + 进步可见。**

### 5.4 工作层面

| 维度 | 方法 |
|------|------|
| **精力管理** | 高精力做决策、低精力做执行 |
| **时间管理** | 重要优先、拒绝低价值会议 |
| **避免内耗** | 快速决策、接受不完美 |
| **工作节奏** | 紧张+放松交替 |

**关键：精力管理比时间管理重要。**

### 5.5 心理层面

| 维度 | 方法 |
|------|------|
| **抗压** | 分解问题、寻求帮助 |
| **情绪** | 运动、冥想、倾诉 |
| **边界** | 工作不渗透生活 |
| **正念** | 关注当下、不焦虑 |

### 5.6 能量杀手与恢复

| 杀手 | 解决 |
|------|------|
| 持续高压 | 张弛有度、周末休息 |
| 无意义会议 | 拒绝/减少 |
| 内耗纠结 | 快速决策 |
| 信息过载 | 精简信息源 |
| 睡眠不足 | 保证睡眠 |

| 恢复方法 | 说明 |
|---------|------|
| 深休息 | 周末彻底休息 |
| 运动 | 30分钟恢复能量 |
| 冥想 | 10分钟精神恢复 |
| 自然接触 | 户外放松 |
| 成就感 | 完成任务记录 |

## 六、做事思维范式

### 6.1 常见思维范式

| 范式 | 说明 | 适用场景 |
|------|------|---------|
| **目标导向** | 先定目标，再分解路径 | 项目规划、职业发展 |
| **问题导向** | 先找问题，再解决 | Bug修复、故障排查 |
| **价值导向** | 先看价值，再做投入 | 技术选型、ROI决策 |
| **用户导向** | 先理解用户，再设计 | 产品设计、需求分析 |
| **系统思维** | 看整体关联，不孤立看 | 架构设计、复杂问题 |
| **迭代思维** | 小步快跑，持续改进 | 产品开发、个人成长 |
| **第一性原理** | 回归本质，重新思考 | 创新方案、根本解决 |
| **逆向思维** | 反向推导，找根因 | 故障排查、问题分析 |
| **对比思维** | 多方案对比，择优 | 技术选型、决策 |
| **二八法则** | 抓关键20%，忽略80% | 时间管理、优先级 |
| **MVP思维** | 最小可行，快速验证 | 产品创新、方案验证 |
| **闭环思维** | 有始有终，持续迭代 | 项目管理、个人成长 |

### 6.2 核心范式详解

#### 第一性原理

**定义**：回归事物本质，从头推导，不依赖已有经验。

**应用**：
- Checkpoint 超时 → 回归本质：快照 = 数据 + 状态 → 分析数据流 + 状态存储
- 背压 → 回归本质：生产 > 消费 → 分析生产速率 + 消费速率

#### 系统思维

**定义**：看整体，理解各部分关联，不孤立看问题。

**应用**：
- Flink 性能调优 → 不只看单个算子，看整个链路（Source → Transform → Sink）
- 实时数仓 → 不只看 Flink，看整个数据链路（CDC → Kafka → Flink → 数据湖）

#### 迭代思维

**定义**：不追求完美，小步快跑，持续改进。

**应用**：
- 开源贡献 → 先提小PR，再提大Feature
- 个人成长 → 每周进步一点点，持续迭代

#### 闭环思维

**定义**：有始有终，Plan → Do → Check → Act。

**应用**：
- 项目管理：规划 → 执行 → 检查 → 调整
- 个人成长：目标 → 执行 →复盘 → 调整

### 6.3 思维范式选择

| 场景 | 推荐范式 |
|------|---------|
| 项目规划 | 目标导向 + 迭代思维 |
| 故障排查 | 问题导向 +逆向思维 |
| 技术选型 | 价值导向 + 对比思维 |
| 架构设计 | 系统思维 + 第一性原理 |
| 个人成长 | 目标导向 + 闭环思维 +迭代思维 |
