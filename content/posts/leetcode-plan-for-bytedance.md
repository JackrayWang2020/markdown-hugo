## 三、刷题技巧

### 3.1 通用模板

#### 二分查找

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

#### 滑动窗口

```python
def sliding_window(s):
    left = 0
    result = 0
    window = {}
    for right in range(len(s)):
        # 扩大窗口
        window[s[right]] = window.get(s[right], 0) + 1
        # 缩小窗口
        while need_shrink(window):
            window[s[left]] -= 1
            if window[s[left]] == 0:
                del window[s[left]]
            left += 1
        # 更新结果
        result = max(result, right - left + 1)
    return result
```

#### DFS模板

```python
def dfs(root):
    if not root:
        return
    # 前序
    dfs(root.left)
    # 中序
    dfs(root.right)
    # 后序
```

#### BFS模板

```python
from collections import deque

def bfs(root):
    queue = deque([root])
    while queue:
        node = queue.popleft()
        for child in node.children:
            queue.append(child)
```

#### 回溯模板

```python
def backtrack(path, choices):
    if end_condition:
        result.append(path[:])
        return
    for choice in choices:
        # 做选择
        path.append(choice)
        backtrack(path, new_choices)
        # 撤销选择
        path.pop()
```
