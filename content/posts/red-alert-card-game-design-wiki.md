## 一、项目概述

**游戏名**：钢铁风暴（暂定，避免商标问题）

**定位**：基于红色警戒世界观的实时卡牌对战手游，目标平台为抖音小游戏

**核心卖点**：
- 红警 IP 风格的军事卡牌，唤醒 80/90 后情怀
- 皇室战争式实时对战，上手快
- 卡牌收集 + 阵营搭配，策略深度够

**参考游戏**：
- 皇室战争（实时对战节奏）
- 炉石传说（卡牌收集深度）
- 红色警戒（世界观与美术风格）

## 二、世界观与阵营

### 2.1 三大阵营

| 阵营 | 风格 | 核心特色 | 红警对应 |
|------|------|---------|---------|
| **盟军** | 科技、精准 | 高单体伤害、远程打击、防御塔强 | 盟军（RA1/2/3） |
| **苏军** | 力量、压制 | 高血量、范围伤害、人海战术 | 苏联（RA1/2/3） |
| **帝国** | 机动、变异 | 变形单位、心灵控制、高爆发 | 尤里军团 + 帝国（RA2/3） |

### 2.2 阵营差异设计

| 维度 | 盟军 | 苏军 | 帝国 |
|------|------|------|------|
| 节奏 | 中速，防守反击 | 慢速，重甲推进 | 快速，骚扰偷袭 |
| 费用效率 | 单卡贵但强 | 单卡便宜，数量取胜 | 中等，但有变形价值 |
| 弱点 | 怕人海 | 怕高单体 | 怕速推 |
| 关键词 | 精准、护盾、飞行 | 护甲、狂暴、溅射 | 潜行、控制、变形 |

## 五、战斗机制

### 5.1 对战规则

| 规则 | 说明 |
|------|------|
| 对战模式 | 1v1 实时对战 |
| 战场 | 竖屏，上下两半，各一个基地 |
| 胜利条件 | 摧毁对方基地（基地血量2000） |
| 时间 | 每局3分钟，超时基地血量多的赢 |
| 费用 | 初始5点，每秒回复1点，上限10点 |
| 手牌 | 始终保持4张手牌，出1张补1张 |
| 卡组 | 30张卡牌，同一卡牌不超过稀有度上限 |

### 5.2 费用曲线

```
费用   1    2    3    4    5    6    7    8+
占比  15%  25%  25%  15%  10%   5%   3%   2%
```

### 5.3 单位行为

| 行为 | 说明 |
|------|------|
| 移动 | 从己方基地向对方基地移动 |
| 攻击 | 进入攻击范围后自动攻击 |
| 寻敌 | 优先攻击最近单位，无单位则攻击建筑 |
| 死亡 | 播放动画后消失 |

### 5.4 特殊机制

| 机制 | 说明 | 来源 |
|------|------|------|
| 护甲 | 减少固定伤害值 | 苏军重型单位 |
| 护盾 | 抵挡一次伤害 | 盟军科技 |
| 潜行 | 未攻击时不可见 | 帝国忍者/幻影坦克 |
| 溅射 | 攻击波及相邻目标 | 天启/光棱/磁暴 |
| 控制 | 持续操控敌方单位 | 尤里/心灵控制 |
| 变形 | 两种形态切换 | 海翼天翼 |
| 冲撞 | 碰到敌人造成额外伤害 | 鬼王/恐怖机器人 |

## 十、核心生态循环设计

### 10.1 玩家生态

```
大R充钱 → 虐0氪 → 很爽，继续充
0氪被虐 → 输了但拿卡 → 慢慢变强 → 偶尔赢一把 → 上头一辈子
大R发现0氪变强 → 再充钱 → 继续虐
→ 无限循环，两边都上头，两头都赚钱
```

### 10.2 输了也有奖励（关键设计）

| 输赢 | 勋章/积分 | 卡牌碎片 | 盒子 | 经验值 |
|------|----------|---------|------|--------|
| 赢了 | ✅ +3 | ✅ +5 | ✅ 1个 | ✅ +50 |
| 输了 | ❌ 不加 | ✅ +2 | ✅ 1个 | ✅ +20 |

**核心原则：输了不空手。0氪越输越强，大R必须持续充钱才能保持碾压。**

### 10.3 运气成分（技术70% + 卡组20% + 运气10%）

| 运气来源 | 说明 | 效果 |
|---------|------|------|
| 抽牌顺序 | 每局手牌随机 | 同卡组每局不同体验 |
| 暴击/闪避 | 10%概率触发 | 逆风局有翻盘希望 |
| 战术卡随机 | 核弹偏移/空袭命中率 | 大R也不敢稳赢 |
| 地图事件 | 突然空投/矿场爆炸 | 每局战场不同 |
| 盒子开奖 | 开出金卡的概率 | 间歇性奖励，老虎机原理 |

**运气的设计目的**：
- 大R赢多输少，但不稳赢 → 继续充钱保优势
- 0氪偶尔天胡翻盘 → 爽一辈子，继续肝
- 输了觉得运气差 → 再来一把
- 赢了觉得自己牛 → 再来一把

### 10.4 勤劳=奖励（肝的经济价值）

| 行为 | 奖励 | 心理钩子 |
|------|------|---------|
| 每天登录 | 免费盒子 | 不来就亏了 |
| 打满10场 | 额外盒子 | 再打两把就够了 |
| 看广告开双倍 | 双倍碎片 | 忍30秒换资源 |
| 凑满开100个盒子 | 爽感释放 | 收集强迫症 |
| 连胜3场 | 连胜奖励 | 差一场了继续打 |

**0氪的成就感**："我没花钱，靠勤劳攒出了一套金卡" → 比花钱赢爽100倍

### 10.5 玩家定位与货币换算

| 玩家 | 投入 | 获得价值 | 定位 |
|------|------|---------|------|
| 0氪 | 每天1小时肝 | ≈ 30元/月 | 免费内容（大R的对手） |
| 微氪 | 30元/月 + 每天30分钟 | ≈ 100元/月 | 稳定收入（主力玩家） |
| 中氪 | 300元/月 | ≈ 500元/月 | 核心玩家（有存在感） |
| 大R | 几千/月 | = = | 利润来源（天神体验） |

**本质：时间=钱，只是货币不同。每个人觉得自己赢了，才是好生意。**
