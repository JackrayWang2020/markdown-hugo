## 五、第3月：项目包装+模拟面试

### 5.1 项目包装（Week 9-10）

#### 项目STAR法则

| 维度 | 说明 |
|------|------|
| **Situation** | 项目背景、业务痛点 |
| **Task** | 你的任务、目标 |
| **Action** | 你做了什么（技术方案、优化） |
| **Result** | 量化成果（性能提升、成本降低） |

#### 项目模板

```
项目名称：XXX实时数据处理平台

背景：
- 业务痛点：数据延迟高、实时性差
- 规模：日处理XX亿条数据，XX TB存储

我的角色：
- 架构师/技术负责人
- 负责整体架构设计和技术选型

技术方案：
- 使用Flink + Kafka + Hudi构建实时数仓
- 设计Exactly-Once语义保证
- 优化背压问题，延迟从X降到Y

量化成果：
- 数据延迟从分钟级降到秒级
- 处理能力提升X倍
- 成本降低Y%
```

#### 项目数量

- 主项目2-3个（深度展示）
- 辅助项目2-3个（广度展示）

### 5.2 简历优化（Week 11）

#### 简历结构

| 模块 | 内容 | 篇幅 |
|------|------|------|
| 基本信息 | 姓名/电话/邮箱/GitHub | 1行 |
| 个人简介 | 3-5句话，突出亮点 | 3-5行 |
| 技能清单 | Flink/Spark/Kafka/... | 5-8行 |
| 工作经历 | 倒序，每段2-3个亮点 | 10-15行 |
| 项目经历 | STAR法则，量化成果 | 20-30行 |
| 开源贡献 | GitHub PR/Issue | 3-5行 |
| 技术分享 | 博客/演讲 | 3-5行 |

#### 简历原则

1. **量化**：不用"优化"，用"提升50%"
2. **动词**：设计/实现/优化/推动/主导
3. **关键词**：Flink/实时/架构/性能/成本
4. **简洁**：1-2页，突出重点

### 6.2 面试技巧

| 技巧 | 说明 |
|------|------|
| **主动引导** | 把话题引到自己熟悉的领域 |
| **量化成果** | 不说"优化"，说"提升50%" |
| **展示深度** | 不只讲what，讲why和how |
| **承认不足** | 不会的坦诚说，展示学习能力 |
| **提问环节** | 问团队规模、技术栈、业务方向 |

### 6.3 谈薪技巧

| 技巧 | 说明 |
|------|------|
| **多offer对比** | 拿到多个offer再谈 |
| **不要先说数字** | 让HR先报价 |
| **总包思维** | 不只看base，看总包 |
| **签字费** | 可以争取签字费 |
| **股票** | 了解股票归属节奏 |
