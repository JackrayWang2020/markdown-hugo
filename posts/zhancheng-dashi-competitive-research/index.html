一、游戏概述#

维度 信息
游戏名 占城大师
类型 卡牌 + 城战 + 领地建造
平台 抖音小游戏
出版 湖北省扬子江影音有限责任公司
过审 2025年11月26日（国新出审〔2025〕2380号）
美术风格 Q版卡通 + 西方奇幻
核心玩法 卡牌对战 + 占领城池 + 领地经营

二、角色/卡牌体系#

2.1 卡牌阵营与种族#

占城大师采用种族阵营设计，而非国家阵营：

种族 风格 代表卡牌
兽人 力量型，高攻击高血量 兽人战士、兽人萨满
神明 法术型，技能强力 天照、神明娘
人类 均衡型，万金油 骑士、弓箭手
精灵 速度型，高闪避 精灵射手
熊猫 特殊型，独特机制 熊猫僧人（T0级卡牌）

2.2 卡牌稀有度#

稀有度 颜色 定位
白卡 ⬜ 普通 基础填充，易获取
蓝卡 🟦 精良 核心组件，版本强势蓝卡备受关注
紫卡 🟪 稀有 战术核心
金卡 🟨 传说 翻盘关键，T0级卡牌多在此
红卡 🔴 史诗 极稀有，强度超标

2.3 T0 级卡牌（强度排行参考）#

根据 B 站攻略视频信息：

卡牌 稀有度 定位 强度原因
熊猫僧人 🟨金 输出+辅助 新手推荐，综合强度超标
天照 🟨金 法术输出 神明体系核心
兽人萨满 🟪紫 范围增益 兽人体系核心
神明娘 🟨金 输出 满配后强度极高

2.4 卡牌养成#

养成维度 说明
等级升级 消耗经验书/素材，提升基础属性
星级突破 消耗同名卡碎片，解锁新技能/提升上限
神器装备 装备专属武器（如弑神之矛），大幅强化
羁绊系统 特定卡牌同时上阵激活额外属性

3.4 占城机制#

阶段 说明
1. 部署 在己方领地放置卡牌单位
2. 推进 单位自动向敌方推进
3. 攻城 到达敌方建筑时开始攻击
4. 占领 摧毁敌方建筑后占领，产出转为己方
5. 胜利 占领敌方主城 = 获胜

四、战斗逻辑#

4.1 对战模式#

模式 说明
竞技场 1v1 排位，天梯积分制
攻城战 攻打 NPC/AI 城池，PVE 推图
联盟战 公会之间争夺领地
乱斗 特殊规则限时玩法

4.2 战斗流程#

1. 选阵容：从卡组选择出战卡牌
2. 布阵：在己方区域放置初始单位
3. 出牌：消耗费用打出手牌
4. 自动战斗：单位自动寻敌攻击
5. 技能释放：英雄/特殊单位手动释放技能
6. 结算：一方主城被摧毁或时间到

4.3 费用系统#

项目 说明
费用回复 每秒自动回复
初始费用 开局给一定费用
费用上限 有上限，防止囤费
费用曲线 卡牌费用从1-9不等

4.4 战斗机制细节#

机制 说明
自动寻敌 单位自动攻击最近敌人
克制关系 种族间存在克制（如兽人克精灵）
技能触发 满足条件自动触发或手动释放
死亡替换 单位死亡后可继续出牌补充
阵型效果 前排坦克 + 后排输出的站位加成

七、对红警卡牌项目的启发#

7.1 值得借鉴的设计#

占城大师设计 红警卡牌适配 启发
领地经营 + 卡牌对战 矿场/兵营 + 出兵 红警本身就有矿场和建筑，天然适配
种族阵营 盟军/苏军/帝国 红警阵营比奇幻种族更有辨识度
克制关系 兵种克制（步兵<坦克<飞行<防空<步兵） 更军事化，更直觉
神器系统 科技升级（给单位装备磁暴线圈/力场盾） 用红警科技替代奇幻装备
羁绊系统 阵营协同（同阵营单位上阵加成） 盟军协同/苏军协同
城战地图 占领敌方矿场/兵营 红警的资源争夺天然适配占城
兑换码获客 同样适用 抖音小游戏标配

7.2 红警卡牌的差异化优势#

维度 占城大师 红警卡牌（我们）
题材 西方奇幻（红海） 军事科幻（蓝海，情怀杀）
美术 Q版卡通 像素军事风（差异化）
阵营 常规种族 盟军/苏军（国民级IP认知）
地图 通用奇幻 现代战场（城市/雪地/沙漠）
超武 无 核弹/铁幕/天气控制器（独有卖点）
目标用户 泛游戏用户 80/90后红警情怀玩家

7.3 需要规避的问题#

占城大师问题 红警卡牌对策
卡牌平衡性差（T0卡过强） 严格数值测试，赛季调整
破解版泛滥（B站大量GM版） 服务端校验 + 反外挂
免费玩家体验差 保证 F2P 玩家每天可免费抽卡
内容消耗快 9赛季规划，逐步释放

八、核心设计对比总结#

维度 占城大师 钢铁风暴（我们）
核心循环 出牌→占城→领地升级→更强卡牌 出兵→占矿→科技升级→更强兵种
对战节奏 ~3分钟 ~3分钟
卡牌数量 ~100+ 首期40，目标165+
阵营 5种族 3阵营（盟/苏/帝）
差异化 领地经营 军事题材 + 超武系统
美术 Q版奇幻 像素军事
受众 泛用户 80/90后情怀 + 新玩家
平台 抖音小游戏 抖音小游戏

核心结论：占城大师验证了"卡牌对战 + 占城经营"在抖音小游戏上的可行性。红警题材比奇幻题材更有辨识度和情怀，是我们最大的差异化武器。超武系统（核弹/铁幕/天气控制器）是占城大师没有的独特卖点。
